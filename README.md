# Proyecto interdisciplinario
4 ° 1, Ivo Fenoglio, Gabriel Ontivero, Franco Marquez.

# Descripcion de Robot Defender
El jugador controla un robot encargado de defender una base central de oleadas progresivas de ataques enemigos. Durante la partida se registran acciones estratégicas como disparos, impactos recibidos, y gestión de recursos. El objetivo es mantener la integridad de la base protegida durante la mayor cantidad de rondas posible.

# Objetivo del proyecto

Objetivos Generales:
Integrar conocimientos de diseño relacional, consulta de datos, algoritmos y estructuras de datos en un proyecto de software real.
Fomentar el trabajo colaborativo, la gestión ágil y la comunicación técnica profesional.

Objetivos Específicos – Base de Datos:
Diseñar un Diagrama Entidad-Relación (DER) y transformarlo a modelo lógico aplicando 1FN, 2FN y 3FN.
Implementar una base de datos de mínimo 8 tablas con integridad de entidad, referencial y de dominio.
Ejecutar operaciones CRUD desde C# y formular consultas complejas: JOIN (INNER/LEFT), GROUP BY + HAVING, SUBQUERIES, funciones agregadas (SUM, AVG, COUNT, MAX, MIN).
Generar reportes analíticos a partir de consultas estructuradas.

Objetivos Específicos – Algoritmos y Estructuras de Datos:
Implementar estructuras estáticas (arrays 1D/2D, registros) y dinámicas (pilas, colas, listas enlazadas).
Aplicar algoritmos de búsqueda (secuencial/binaria) y ordenamiento (burbuja, inserción, selección).
Utilizar recursión o iteración optimizada en lógica de juego, justificando su complejidad temporal/espacial.
Gestionar persistencia local mediante archivos de texto y binarios para backups o logs de depuración.

Objetivos Específicos – Metodología y DevOps:
Gestionar el proyecto con Scrum: backlog, sprints de 4 semanas, daily meetings, review y retrospectiva.
Aplicar Git con ramas, commits semánticos, pull requests y resolución de conflictos.
Documentar el repositorio (README.md, CHANGELOG.md, wiki, estructura de carpetas comentada).
